# Week 1: Data Acquisition, Cleaning, and Exploratory Data Analysis

## Project Overview
This project uses Python to explore the scikit-learn diabetes dataset. It includes data acquisition, data quality checks, exploratory data analysis, and visualizations.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Key Activities
- Loaded and inspected the dataset
- Checked for missing values and duplicate records
- Created a cleaned dataset
- Generated visualizations to explore distributions and relationships
- Summarized findings and limitations

## Dataset
The dataset contains 442 records and 11 columns, including 10 standardized predictor features and a quantitative target representing disease progression one year after baseline.

## Files
- Project report
- Raw dataset CSV
- Cleaned dataset CSV
- Jupyter Notebook (if included)

## Disclaimer
This is an educational data analysis project. Correlations do not establish causation, and the dataset is not intended for individual medical diagnosis.
